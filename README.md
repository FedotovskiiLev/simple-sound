# simple sound

Минималистичный звуковой пульт, который работает прямо в браузере. Один `index.html`, никаких серверов, библиотек, регистрации или загрузки аудио в интернет.

## Возможности

- Загрузка нескольких аудиофайлов сразу или перетаскиванием.
- Страницы (банки) по **10 звуков**; большие пачки раскладываются автоматически.
- Воспроизведение/остановка одним нажатием; одновременно играет один звук.
- Перестановка и удаление звуков; создание, переименование и удаление страниц.
- Переключатель **«Всё одним списком»**. Даже в этом режиме горячие клавиши относятся к выбранной странице.
- Локальное автосохранение в IndexedDB, включая сами аудиофайлы.
- Перенос настроенного пульта другому человеку через **ZIP**: экспортировать/импортировать одну страницу или весь набор.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `1`–`9`, `0` | Запустить или остановить соответствующий звук **активной страницы** |
| `Tab` | Следующая страница (по кругу) |
| `Shift + Tab` | Предыдущая страница |
| `Esc` / `Space` | Остановить звук |

> В приложении `Tab` специально переключает страницы, а не фокус элементов интерфейса. `Space` сохраняет обычное поведение, когда фокус находится на кнопке или чекбоксе.

## Обмен наборами

Меню **Экспорт** позволяет скачать ZIP с выбранной страницей или со всеми страницами. Внутри лежат исходные аудиофайлы и `manifest.json` с именами и порядком. Base64 не используется, архив подходит для передачи другому человеку.

Меню **Импорт** предлагает:
- **Добавить страницу из ZIP** — вставит ещё одну страницу без удаления текущих звуков.
- **Восстановить всё из ZIP** — заменит весь текущий набор после подтверждения.

ZIP не отправляется на сервер: всё чтение и сохранение выполняются в браузере. Поддерживаются архивы, созданные самим simple sound (обычные ZIP без сжатия содержимого).

## Запуск

Откройте [index.html](./index.html) в браузере или опубликуйте его через GitHub Pages. Звуки хранятся **на устройстве и в браузере**, а не в репозитории. Если очищать данные сайта, аудиобиблиотека тоже удалится — поэтому для резервной копии используйте экспорт ZIP.
