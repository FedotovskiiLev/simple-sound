# simple sound

Минималистичный звуковой пульт прямо в браузере. Один `index.html` — без сервера, библиотек, аккаунтов и отправки звуков в интернет.

## Возможности

- Добавляй аудиофайлы пачками или drag-and-drop.
- Автоматические страницы (банки) по 10 звуков, с горячими клавишами `1`–`9` и `0`.
- Переименовывай звуки кнопкой с карандашом или двойным кликом по названию. `Enter` — сохранить, `Esc` — отменить.
- Перемещай и удаляй звуки; добавляй, переименовывай и удаляй страницы.
- Переключай **«Всё одним списком»**: вкладки скрываются, список становится общим, переключатель остаётся на месте.
- Два режима для живого выступления: **Очередь** и **Радио**.
- Автосохранение звуков и имён локально в IndexedDB.
- Импорт/экспорт одной страницы или всего набора в ZIP с `manifest.json`.

## Клавиатура

| Клавиша | Действие |
| --- | --- |
| `1`–`9`, `0` | Играть/остановить соответствующий звук активной страницы |
| `Tab` / `Shift + Tab` | Следующая / предыдущая страница (по кругу) |
| `S` | Включить / выключить очередь |
| `R` | Включить / выключить радио |
| `Esc` | Остановить текущий звук |
| `Space` в обычном режиме | Остановить играющий звук |
| `Space` в очереди | Первый раз — воспроизвести звук; второй — остановить; следующий — воспроизвести следующий и т. д. |
| `Space` в радио | Сразу сменить звук на другой случайный |
| `Backspace` в радио | Выключить радио и остановить звук |

В режиме **Очередь** звуки идут по порядку, но **не запускаются автоматически**. Когда трек заканчивается, следующий ждёт пробела. После последнего очередь начинается заново.

В режиме **Радио** музыка/звуки играют **непрерывно**: после окончания одного трека выбирается следующий случайный. Если есть выбор, один и тот же трек не повторяется непосредственно два раза подряд.

Оба режима берут звуки с **текущей страницы**, а если включено «Всё одним списком» — **со всех страниц**. Режимы взаимоисключающие. Ручное воспроизведение по кнопке или цифре возвращает обычный режим. Горячие клавиши `S` / `R` работают и при русской раскладке по физическому расположению клавиш.

> `Tab` в приложении занят переключением страниц, кроме случаев редактирования названия звука.

## ZIP и JSON

Экспорт включает оригинальные байты аудиофайлов и `manifest.json` со страницами, порядком, **новыми видимыми именами** (`name`), исходными именами файлов (`originalName`), размерами и MIME-типами. Переименование не изменяет сам аудиофайл.

- **Экспорт → Текущую страницу / Все страницы** — скачать готовый ZIP.
- **Импорт → Добавить страницу** — дополнить существующую библиотеку.
- **Импорт → Восстановить всё** — заменить весь набор после подтверждения.

Для новых архивов сохранён формат версии 1, чтобы оставалась совместимость с предыдущими экспортами simple sound. ZIP создаётся в стандартном формате без сжатия содержимого (многие форматы аудио уже сжаты), Base64 не используется.

## Запуск

Открой [index.html](./index.html) в браузере или размести файл на GitHub Pages. Все аудиофайлы хранятся **локально в данных сайта**, а не в репозитории. Если очищать данные браузера, библиотека удалится — используй экспорт ZIP для резервной копии.
